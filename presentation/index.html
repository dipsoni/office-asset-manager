The Business Problem & Our Solution

Why Traditional Asset Tracking Fails

Companies lose thousands of dollars every year when employees resign or change departments without returning assigned laptops, monitors, chargers, and mobile equipment.

❌ The Old Manual Excel Way

  • ✕
    Spreadsheet Version Desync Multiple managers editing conflicting spreadsheets leads to missing equipment.
  • ✕
    Overlooked Resignations HR offboards an employee, but IT is never notified of assigned laptops or mobile SIMs.
  • ✕
    Lapsed Warranties Hardware fails with expired warranty claims because expiry dates weren't monitored.

✅ The AssetVault Solution

  • ✓
    Real-Time Single Source of Truth All assets, serial numbers, brands, and custodians synced directly in cloud SQLite.
  • ✓
    Automatic Resignation Detection Changing employee status to "Resigned" auto-closes assignments and stages equipment for clearance.
  • ✓
    Smart Warranty Radar Categorized alerts for warranties expiring in ≤30, ≤60, and ≤90 days.

Engineering & Architecture

Modern, Robust Full-Stack Architecture

Engineered for rapid response times, zero external database subscription overhead, and high portability.

⚛️

Frontend (React 19)

Built with modern React 19 and Vite 8 for blazing 3-second compilation, Tailwind CSS for luxury dark-mode aesthetics, and Recharts for dynamic visual analytics.

⚡

Backend (Node.js & Express 5)

Single unified server delivering REST APIs and compiled static assets. Uses Node.js 24 native SQLite with WAL mode for ultra-fast, zero-overhead storage.
